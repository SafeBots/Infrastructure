# 90safebox dracut module

Copy this directory to `/usr/lib/dracut/modules.d/90safebox` on the build root (the two scripts `safebox-seal.sh` and `safebox-unseal.sh` from `common/boot/` are picked up from the module directory if copied alongside, otherwise from `/usr/lib/safebox/` where `install-base.sh` places them), install `safebox.conf` as `/etc/dracut.conf.d/safebox.conf` so that `add_dracutmodules+=" safebox systemd-veritysetup zfs "` is in effect, make sure `tpm2-tools`, `zfs`, and `dracut` (not `initramfs-tools`) are installed, and rebuild the initramfs with `dracut --force --kver <version>`. The module installs the TPM and dm-verity kernel modules, the tpm2-tools binaries and their dlopen'ed TCTI libraries, the two scripts under `/usr/lib/safebox/`, and `safebox-unseal.service`, which it enables in `initrd.target` and orders before every `zfs-import` unit and `initrd-root-fs.target`; the unit's `ConditionKernelCommandLine=safebox.datadisk` means an initramfs built with this module is inert on a kernel command line that does not carry the safebox parameters, which keeps the build VM itself bootable.
